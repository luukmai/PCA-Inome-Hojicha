คู่มืออ่านผล (How to read classification results)

1) ชื่อชนิดชาที่แสดงตัวใหญ่: คือชนิดที่ได้คะแนนโหวตมากที่สุดจาก Reference ที่ใกล้ที่สุด 3 ตัวอย่าง (k = 3) ไม่ใช่การยืนยันชนิดชา 100%

2) Neighbour votes: จำนวน Reference ใน 3 อันดับแรกที่เป็นแต่ละชนิด เช่น 2/3 หมายถึง 2 จาก 3 Reference เป็นชนิดนั้น (ประมาณ 66.7% ของเสียงโหวต) ส่วน 1/3 หมายถึง 1 เสียง

3) Nearest distance: ระยะห่างของ Unknown จาก Reference ที่ใกล้ที่สุด คำนวณจาก Sensor ที่เลือกหลังปรับสเกลแล้ว ค่ายิ่งต่ำหมายถึงใกล้กว่าเมื่อเทียบภายใต้ชุด Sensor และ Reference Library เดียวกัน ไม่ควรเทียบค่าระหว่างการตั้งค่า Sensor หรือ Library ที่ต่างกันโดยตรง

4) ทำไมขึ้น Uncertain / Review? ระบบจะแสดงสถานะนี้เมื่อเสียงโหวตของกลุ่มอันดับหนึ่งต่ำกว่า 67% หรือ nearest distance มากกว่า 3.5 ดังนั้นผล 2/3 (66.7%) จึงยังถูกจัดเป็น Uncertain ตามเกณฑ์ปัจจุบัน

ข้อควรระวัง: vote share เป็นสัดส่วนเสียงจากเพื่อนบ้าน ไม่ใช่ calibrated probability และค่า distance 3.5 เป็นเกณฑ์คัดกรองเบื้องต้นของ prototype ไม่ใช่ค่าขอบเขตที่ผ่านการ validation แล้ว หากขึ้น Uncertain ให้รายงานว่า “ยังจำแนกไม่ได้อย่างมั่นใจ” และตรวจสอบ reference/การวัดเพิ่มเติม

กราฟ 3 มิติ: PC1 × PC2 × PC3 · ลากเพื่อหมุนกราฟ และซูมเพื่อดูตำแหน่งแต่ละตัวอย่าง

โหมด Mean แสดง 1 จุดต่อกลุ่ม โดยเฉลี่ย PC scores ของ replicates ใน Calibration PCA เดิม · PCA ใช้ 8 sensors: G2, G3, G5, G6, G10, G11, G13, G14 ไม่ขึ้นกับชุด Sensor ที่เลือกสำหรับ Classification
การอ่านกราฟ: จุด Reference สีเดียวกันคือชนิดชาเดียวกัน ส่วน Unknown เป็นรูปเพชร หาก Unknown อยู่ใกล้กลุ่มใดใน PCA อาจบ่งชี้ว่ามีรูปแบบ Sensor คล้ายกลุ่มนั้น แต่ PCA เป็นการลดมิติและแสดงความคล้ายเชิงภาพ ไม่ใช่ผลยืนยันชนิดชา และอาจไม่ตรงกับผล nearest-neighbour ทุกกรณี
ความหมายผลลัพธ์: ระบบใช้ nearest-neighbour comparison กับ Reference Library ที่อัปโหลด โดย confidence เป็นสัดส่วนคะแนนจากเพื่อนบ้านใกล้สุด ไม่ใช่ความน่าจะเป็นที่ผ่านการสอบเทียบทางสถิติ ควรมี reference replicates หลายตัวอย่างต่อชนิดชา และควรพิจารณาระยะห่างด้วย หากตัวอย่างไม่ใกล้กับ reference ใดชัดเจน ให้จัดเป็น “ต้องตรวจสอบ / อาจเป็นชาอื่น” ไม่ควรยืนยันชนิดจากคะแนนเพียงอย่างเดียว
