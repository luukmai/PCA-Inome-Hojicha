ลดจำนวน Sensor และ Cycle เพื่อจำแนกชา 10 ชนิด

วิเคราะห์จาก FFT features ที่คำนวณไว้แล้วของชา 10 ชนิด โดยเปรียบเทียบชุดเซนเซอร์ 1, 2, 3 ตัวกับชุดเต็ม 12 ช่อง และเปรียบเทียบช่วง cycle ที่ใช้

ผลที่ได้จากข้อมูลชุดนี้ (screening result)
ตัวอย่าง3010 ชนิด × 3 replicates
ช่องเซนเซอร์ในไฟล์12G1, G2, G3, G5–G8, G10–G14
ชุดที่ดีที่สุดในรอบค้นหา66.7%Balanced accuracy; 2–3 sensors
ชุดเต็ม 12 ช่อง63.3%ดีที่สุดที่ Cycle 3–5 ในหน้าต่างที่ทดสอบ

สรุปเบื้องต้น: ในการค้นหาชุดเซนเซอร์และช่วง cycle นี้ พบชุด 2 เซนเซอร์ G5 + G8 ใช้ Cycle 3–5 ได้ 66.7% และชุด 3 เซนเซอร์ G3 + G8 + G14 ใช้ Cycle 3–5 ได้ 66.7% เทียบกับ 63.3% เมื่อใช้ทั้ง 12 ช่องใน Cycle 3–5 — ดีขึ้นเพียง 3.4 จุดเปอร์เซ็นต์สำหรับชุด 3 เซนเซอร์ และยังไม่ถือว่าเป็นการยืนยันว่าดีกว่าจริง เพราะได้เลือกชุดที่ดีที่สุดหลังจากค้นหาหลายชุด

เปรียบเทียบ Balanced Accuracy ตามจำนวนเซนเซอร์

กราฟแสดงคะแนนดีที่สุดที่พบในแต่ละจำนวนเซนเซอร์และช่วง cycle ที่ทดสอบ ไม่ใช่คะแนนทดสอบอิสระหลังการเลือกชุด

ชุดที่ได้คะแนนสูงสุดในแต่ละช่วง Cycle
ช่วง Cycleจำนวนเซนเซอร์ชุดเซนเซอร์ที่ดีที่สุดในรอบค้นหาBalanced accuracyคะแนนแต่ละ fold

Balanced accuracy เป็นค่าเฉลี่ย recall ของทั้ง 10 กลุ่ม จึงเหมาะกว่า accuracy ธรรมดาเมื่อสนใจความสามารถแยกแต่ละชนิดชาเท่า ๆ กัน ค่า 66.7% ไม่ได้แปลว่าทุกชนิดชาแยกได้ 66.7% เท่ากัน

ข้อมูลเซนเซอร์จากหน้าจอเครื่อง

ข้อมูลด้านล่างถอดจากภาพ Sensor data sheet ที่ส่งมา ใช้เป็นข้อมูลประกอบบนเว็บไซต์เท่านั้น สเปกการตอบสนองของผู้ผลิตไม่ได้ยืนยันว่าเซนเซอร์ตรวจจับสารระเหยในชาได้จำเพาะ

ลำดับในหน้าจอรุ่นเซนเซอร์วัสดุการตอบสนองที่ระบุในหน้าจอSensitivity ตามหน้าจอ

ข้อจำกัดสำคัญ: ข้อมูล Excel ใช้ชื่อช่อง G1, G2, G3 ฯลฯ แต่ภาพฮาร์ดแวร์แสดงชื่อ MQ/TGS เรียงลำดับ 1–15 โดยยังไม่มีตาราง mapping ยืนยันว่า G แต่ละช่องตรงกับ MQ/TGS รุ่นใด จึงยังไม่สามารถระบุได้ว่า G5 + G8 คือ MQ/TGS ตัวไหน ห้ามเทียบลำดับ G กับลำดับในภาพโดยตรงจนกว่าจะยืนยัน wiring/channel mapping

วิธีคำนวณ
  1. ตัดแถว Blank ออก และเฉลี่ย FFT features ของแต่ละ replicate ภายในช่วง cycle ที่ทดสอบ
  2. ทดสอบช่วง Cycle 1–3, 2–4, 3–5, 4–6, 5–7 และ 4–7
  3. ไล่ชุดเซนเซอร์ 1, 2 และ 3 ตัวจาก 12 ช่องที่มีข้อมูล พร้อมเปรียบเทียบชุดเต็ม 12 ช่อง
  4. ใช้ Linear SVM พร้อม imputation และ standardization ภายใน pipeline ประเมินด้วย Stratified 3-fold cross-validation (30 แถวตัวอย่างระดับ replicate, 10 classes)

ต้องอ่านผลอย่างระวัง: มีเพียง 3 replicates ต่อชนิดชา และเลือกคะแนนสูงสุดจากชุดเซนเซอร์จำนวนมาก จึงมีความเสี่ยงต่อการเลือกโมเดลที่ฟลุค (selection optimism) คะแนนนี้เป็น exploratory screening ไม่ใช่ผลยืนยันความแม่นยำกับตัวอย่างใหม่ และยังไม่พิสูจน์ว่าสามารถถอดเซนเซอร์ออกจากฮาร์ดแวร์ได้จริง

ขั้นต่อไปควรใช้ nested cross-validation หรือกำหนดชุดเซนเซอร์จาก training folds เท่านั้น แล้วทดสอบกับการวัดซ้ำคนละวัน/ชุดตัวอย่างใหม่ รวมถึงตรวจสอบว่า sensor mapping ตรงกันก่อนทดลองลดฮาร์ดแวร์
