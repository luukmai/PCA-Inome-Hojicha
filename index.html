Baseline correction

Corrected response = Sampling − same-cycle Resting response

Blank vial เป็น QC แยกต่างหาก ไม่ควรนำมาหักออกอัตโนมัติจากทุก sample

Important interpretation checks

  • อย่านำ PCA scores จากคนละ model / preprocessing มาเทียบในกราฟเดียวกัน
  • จำนวน replicate น้อยควรใช้เป็น exploratory result เท่านั้น
  • ตรวจสอบ sensor mapping ระหว่าง G1–G15 กับรุ่น MQ/TGS ก่อนรายงาน
  • ตรวจสอบ blank, drift, pump/flow stability และ heater status ก่อนตัดสินว่า sample ไม่ตอบสนอง
  • บันทึก cycle window และวิธีเฉลี่ยทุกครั้งเมื่อ update PCA

01 · Import your data

รองรับ .xlsx, .xls และ .csv แบบตาราง wide format: 1 แถว = 1 replicate / sample

เลือกไฟล์ข้อมูล

รองรับไฟล์ Raw eNose export (.xlsx/.csv) ที่มีคอลัมน์ Cycle Loop, Mode_clean, Sample_Group, Replicate และ G1–G15 — ระบบจะหา sheet ที่เป็น Raw ให้อัตโนมัติ แล้วคำนวณค่าเฉลี่ย Sampling − Resting ราย Cycle ให้เอง หรือใช้ตารางสรุปที่มี 1 แถวต่อ sample-replicate และคอลัมน์ sensor ก็ได้

ข้อมูลตัวอย่าง Demo A / Demo B เท่านั้น · ไม่ใช่ผลทดลองจริง · ลองแก้ไขหรืออัปโหลดไฟล์ของคุณได้

02 · Preview / edit table

ข้อมูลตัวอย่างสำหรับทดลองเท่านั้น · วาง CSV หรือแก้ตัวเลข แล้วกด Preview data

03 · Choose columns and calculate PCA

เลือกคอลัมน์กลุ่มและ sensor features ก่อนสร้าง PCA — ระบบจะ standardize แต่ละ sensor ด้วย Z-score แล้วคำนวณ PCA จากแถวที่นำเข้า

ยังไม่ได้คำนวณ
PCA ที่คำนวณในหน้านี้เป็นผลใหม่จากข้อมูลที่อัปโหลด ไม่ได้แก้ไข dataset ที่เผยแพร่ในหน้า Pure tea หรือ Blend จนกว่าจะนำไฟล์ต้นฉบับที่ผ่าน QC มาอัปเดต
