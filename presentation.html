04 · Preprocessing

From raw signals to sensor features

The aim is to compare samples using a consistent feature-extraction procedure.

Resting correction

Corrected response = Mean Sampling − Mean Resting

Resting is matched to the same cycle before subtraction.

Cycle selection

Average cycles 2–6

Five cycles are averaged to create one feature vector per replicate for the relevant recent analyses.

G2G3G5G6G10G11G13G14

ภาษาไทย

คำนวณ Sampling ลบ Resting ใน Cycle เดียวกัน จากนั้นเลือก Cycle 2–6 และเฉลี่ยเป็นหนึ่งชุดค่าต่อ Replicate

ENGLISH

For each cycle, subtract the mean resting response from the mean sampling response. Cycles 2–6 are then averaged to form one feature vector per replicate.

05 · Pattern exploration

PCA: visualizing aroma fingerprints

PCA transforms correlated sensor features into principal components that summarize variation in the dataset.

What the axes mean

PC1 captures the largest share of variation.

PC2 captures the next largest share.

PC3 captures the third largest share.

How to read the plot

Points close together have more similar scores in the displayed PCA space. Overlap suggests that groups are not clearly separated in those components.

06 · Classification concept

From PCA exploration to KNN

ภาษาไทย

KNN เปรียบเทียบ feature vector ของ Unknown กับ Reference ที่ผ่าน preprocessing แบบเดียวกัน แล้วเลือก Reference ที่มีระยะห่างน้อยที่สุด K ตัว

ENGLISH

K-nearest neighbours compares an unknown feature vector with preprocessed reference measurements, then selects the K closest reference measurements by distance.

Distance-based comparison

d(U,R) = √[ mean( ((Uₛ − Rₛ) / SDₛ)² ) ]

Standardized Euclidean-style distance across the selected sensors.

Neighbour voting

With K = 3, the nearest three reference measurements vote for their tea class. Replicates from the same tea class must be grouped under the same class label.

1/3 · 2/3 · 3/3

Important limitation

A vote fraction is not a calibrated probability. Any confidence threshold (such as 67%) is a software decision until validated against known test samples. Distance thresholds also require validation.

08 · Chemical profiling

Connecting sensor fingerprints with chemistry

HS-SPME-GC-MS

Profiles volatile compounds and relative peak areas, then groups compounds by chemical class and aroma contribution.

Floral / FruitySweet / CaramelRoasted / NuttySmoky / BitterFermented / EarthyCitrus / Bright

Total Phenolic Content (TPC)

TPC is reported as gallic acid equivalents (GAE). The existing dashboard notes values as solution concentration in µg GAE/mL, not mg GAE/g dry tea.

Why integrate methods?

eNose describes sensor-response patterns; GC-MS identifies volatile compounds; TPC estimates total phenolic content. Integrating them can provide complementary evidence, but comparisons require matched samples and compatible experimental conditions.

Data boundary: the 6-group GC-MS profile covers Hojicha, Hojicha suspect, Inome and Inome suspect. A separate GC-MS summary workbook contains tea samples A–H. Do not assume every dataset covers the same samples.

09 · Learning outcomes & next steps

What have we achieved — and what remains?

What we have built

  • Organized tea reference and blend datasets.
  • Established a resting-corrected feature workflow for selected analyses.
  • Built PCA visualizations and an upload-based identification workspace.
  • Integrated eNose, GC-MS and TPC analysis sections in one dashboard.

What needs further validation

  • Reference/unknown measurement-day effects and instrument drift.
  • Sensor mapping and instrument QC metadata.
  • KNN class-label grouping and thresholds.
  • Blend prediction performance on independent samples.
  • Matched sample sets for eNose–GC-MS–TPC integration.

Key takeaway

eNose provides a promising way to explore tea aroma fingerprints. The current work establishes a data-analysis workflow and interactive tools; robust classification and quantitative prediction still require careful validation.

ภาษาไทย

สิ่งที่ได้คือ workflow สำหรับจัดการและวิเคราะห์สัญญาณ eNose รวมถึงเครื่องมือแสดงผลแบบ interactive แต่การจำแนกและทำนายเชิงปริมาณยังต้องผ่านการตรวจสอบความถูกต้องเพิ่มเติม

ENGLISH

The project has established an eNose data-processing and visualization workflow. Reliable classification and quantitative prediction still require further validation.
