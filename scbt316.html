RESEARCH CASE STUDY

eNose: อ่านลายนิ้วมือกลิ่นของชา

ตัวอย่างการประยุกต์แนวคิดด้านการเตรียมตัวอย่าง การวัดสัญญาณ และการวิเคราะห์ข้อมูล เพื่อเปรียบเทียบรูปแบบกลิ่นของชา

eN
SENSOR ARRAY
FROM SIGNAL TO PATTERN

ขั้นตอนการศึกษา eNose

กดแต่ละขั้นตอนเพื่อดูว่าข้อมูลเปลี่ยนจากสัญญาณดิบไปสู่การเปรียบเทียบกลุ่มชาได้อย่างไร

MEASUREMENT CONTEXT

ตัวอย่างเงื่อนไขการวัด

10 s
REST

ช่วงพักก่อนเริ่มเก็บสัญญาณ

120 s
SAMPLING

ช่วงเก็บ sensor response

60 s
PURGING

ช่วง purge ระหว่างรอบ

200
FLOW RATE

ค่าการไหลตาม protocol

DATA ANALYSIS

จาก response ไปสู่ aroma fingerprint

01 · PREPROCESSING

Resting correction

คำนวณ corrected response (Sampling − Resting) และสรุปข้อมูลเป็น feature ของแต่ละตัวอย่าง

02 · STANDARDIZATION

Z-score normalization

ปรับสเกล sensor แต่ละตัวเพื่อให้เปรียบเทียบตัวแปรที่มีช่วง response ต่างกันได้

03 · DIMENSION REDUCTION

Principal Component Analysis

ลดมิติ feature หลาย sensor เพื่อสำรวจรูปแบบความคล้ายหรือแตกต่างระหว่างตัวอย่าง

04 · INTERPRETATION

การตีความและตรวจสอบ

พิจารณาการกระจายของ replicate และใช้ validation ก่อนสรุปความสามารถในการจำแนกหรือทำนาย
