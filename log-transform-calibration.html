3. Log transformation ที่ใช้

ข้อมูลมีค่าบวกและลบ จึงใช้ ln(x) โดยตรงไม่ได้ การทดสอบนี้ใช้ signed log:

f(x) = sign(x) × ln(1 + |x|)

  • Raw: ไม่แปลงข้อมูล
  • Signed log pointwise: แปลงทุก time point ก่อนเฉลี่ย
  • Signed log after mean: เฉลี่ย feature ก่อนแล้วจึงแปลง

Signed log เป็นวิธีจัดการค่าที่ติดลบเพื่อทดสอบแนวคิด log transform ไม่ใช่การยืนยันว่าเป็นสูตรที่อาจารย์ต้องการ ควรยืนยันสูตรก่อนเลือกเป็น final analysis

4. Data processing

  • Blend วันที่ 20-Oct-2026: Asahi (C) : Ujitawara (H)
  • Sampling cycles 1–7; ใช้ 30 วินาทีสุดท้ายของแต่ละ cycle
  • เฉลี่ยช่วงท้ายของแต่ละ cycle แล้วเฉลี่ยเป็นหนึ่ง feature vector ต่อ replicate
  • 8 observations: 25%, 50%, 75% Ujitawara (2–3 replicates ต่อระดับ)
  • StandardScaler และ PLS fit ใหม่ภายในแต่ละ LOOCV fold

มีเพียง 8 replicates จาก 3 blend levels ผลนี้เป็น pilot และยังไม่ใช่หลักฐานว่าโมเดลทำนาย Unknown ได้แม่นยำ
