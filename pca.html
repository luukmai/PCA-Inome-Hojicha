Step 1 — Raw data

ข้อมูลต้นทางคือค่าเฉลี่ยสัญญาณในช่วง Resting และ Sampling ของแต่ละ Cycle จากไฟล์ eNose โดยหนึ่ง observation คือหนึ่ง Replicate ของชา (รวม 30 จุด) และแต่ละ Sensor เป็นตัวแปรหนึ่งคอลัมน์

Raw response = mean(Sampling signal within 120 s)

ข้อมูลที่นำมาวิเคราะห์มี 10 ชนิดชา × 3 Replicates และมีค่า Sensor 12 ช่อง ได้แก่ G1, G2, G3, G5, G6, G7, G8, G10, G11, G12, G13, G14

Step 2 — Resting baseline correction

หักสัญญาณ Resting ของ Sensor เดียวกันใน Cycle เดียวกันออกจาก Sampling ก่อนนำไปเฉลี่ยข้าม Cycle เพื่อชดเชยสัญญาณพื้นฐานของรอบนั้น

Corrected response(i, cycle) = Sampling(i, cycle) − Resting(i, cycle)

ตัวอย่าง: ถ้า G2 มี Sampling = 51.10 และ Resting = 22.76 ใน Cycle 2 จะได้ corrected response = 28.34

Daily blank ไม่ถูกนำมาหักอัตโนมัติ เพราะ Blank วัดต้นวันและอาจไม่แทน background ตลอดวัน การหัก Blank จึงควรเป็น sensitivity analysis แยกต่างหาก

Step 3 — Cycle selection

เลือกเฉพาะ Cycle 2, 3, 4, 5 และ 6 ของแต่ละ Replicate แล้วคำนวณค่าเฉลี่ยของ Sensor นั้น ๆ หลังทำ baseline correction (หรือ Sampling ดิบหากเลือก Raw mode)

Feature = (X₂ + X₃ + X₄ + X₅ + X₆) / 5

ทุกกลุ่มใช้ช่วง Cycle เดียวกัน เพื่อให้เปรียบเทียบกันได้โดยไม่ปะปนกับผลจาก Cycle window ที่ต่างกัน

Step 4 — Sensor selection

เลือกชุด Sensor เพื่อเปรียบเทียบผลของการลดจำนวน Sensor โดยใช้ observation เดิม 30 จุดและ Cycle 2–6 เหมือนกันทุกชุด

12: G1 G2 G3 G5 G6 G7 G8 G10 G11 G12 G13 G14
8: G2 G3 G5 G6 G10 G11 G13 G14
5: G5 G14 G8 G13 G12
3: G5 G14 G8

การลด Sensor มีเป้าหมายเพื่อดูว่าสามารถลดจำนวนช่องวัดโดยยังคงข้อมูลที่ใช้แยกกลุ่มไว้ได้มากน้อยเพียงใด

Step 5 — Z-score normalization

ปรับสเกลแยกตาม Sensor โดยคำนวณค่าเฉลี่ยและส่วนเบี่ยงเบนมาตรฐานจาก 30 observations ของ Sensor นั้น แล้วแปลงค่าทุก observation

Z = (X − μ) / σ

μ คือค่าเฉลี่ยของ Sensor และ σ คือ sample standard deviation ของ Sensor นั้น ทำให้ Sensor ที่มีช่วงค่าต่างกันไม่ครอบงำ PCA เพียงเพราะมีตัวเลขขนาดใหญ่กว่า

Step 6 — Principal Component Analysis

นำ Z-score matrix ไปคำนวณ covariance matrix, eigenvalues และ eigenvectors จากนั้น project ตัวอย่างลงบนแกน PC1, PC2 และ PC3

Explained variance of PCk = λk / Σλ × 100%

เปอร์เซ็นต์ variance บอกสัดส่วนความแปรปรวนที่แต่ละแกนอธิบายได้ ไม่ใช่ accuracy ในการจำแนกชา ส่วน Silhouette score ใช้ชื่อกลุ่มชาประเมินภายหลังว่าแต่ละจุดอยู่ใกล้กลุ่มตัวเองและห่างจากกลุ่มอื่นเพียงใด

How to read the result

  • จุดหนึ่งจุดแทนหนึ่ง Replicate; สีแทนชนิดชา
  • จุดของชนิดชาเดียวกันอยู่ใกล้กันมาก แปลว่า Replicates มีแนวโน้มคล้ายกันใน PCA space
