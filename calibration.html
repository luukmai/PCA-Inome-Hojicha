05 · What this pilot tells us

  • Multiple eNose sensors can be combined into a regression model that outputs blend proportion.
  • The current C:H dataset is too small and has too few calibration levels for robust quantitative prediction.
  • The A:F experiment should be calibrated separately using known A:F ratios, including pure A and pure F endpoints if feasible.
  • Unknown samples should be evaluated only after independent validation with blends of known composition.
Do not apply this C:H model to A:F. Different tea identities require a new calibration model. Avoid mixing samples measured on different days without controlling or modelling day-to-day instrument variation.
